## Science model & physical assumptions

- **Source redshift**: z = <0.091>
- **Galactic absorption**: nH = <4.6e20> cm⁻² (fixed; source: HI4PI, 2016A&A...594A.116H)
- **Spectral model**: `TBabs * apec` (thermal plasma, solar abundances from <Anders & Grevesse 1989>)
- **Fitting statistic**: C-stat (Cash statistic), **not** chi-squared
- **Fitting band**: 0.5–7.0 keV (EPIC-pn); 0.5–8.0 keV (ACIS-S)
- **Abundance table**: `aspl` (Asplund et al. 2009, 2009ARA&A..47..481A)
- **Cosmology**: H₀ = 70 km s⁻¹ Mpc⁻¹, Ω_m = 0.3, Ω_Λ = 0.7
  (use `astropy.cosmology.FlatLambdaCDM`)

**Known data quality issues**:

  GTI already applied in data/gti/. Do not re-filter.">
- <e.g. "Chandra ObsID 12345: chip gap crosses the target at Y = 2048 px.

1. Place it in the appropriate `src/` subdirectory.
2. Add a module docstring explaining its purpose and usage.
3. Add a corresponding entry to `prompts/` (see TEMPLATE).

## Key commands

```bash
# Reduce XMM data (SAS must be initialised)
python src/reduction/xmm_reduce.py --obsid <0123456789> --out data/

# Extract spectra for a given region
python src/spectral/extract.py --region regions/core.reg --out data/spectra/

# Run spectral fit
python src/spectral/fit.py --spec data/spectra/core --model tbabs_apec \
    --nh 4.6e20 --redshift 0.091 --out results/fits/core.json

# Generate thermodynamic maps
python src/spectral/maps.py --grid regions/voronoi_grid.fits \
    --fits results/fits/ --out results/maps/

# Run MCMC on best-fit region
python src/mcmc/sample.py --config results/fits/core.json \
    --nwalkers 64 --nsteps 5000 --out results/mcmc/core_chains.h5
```

## Agent behaviour rules (project-specific additions)

1. **Spectral fitting**: Always run `fit.py` on a single test spectrum
   (`data/spectra/bkg_region/`) before running on the full grid.
2. **MCMC**: Always set and log a random seed. Default: `seed = 42`.
   Store it in the output HDF5 as an attribute.
3. **Figures**: Use the colour scale defined in `src/utils/style.py`.
   Do not override it without discussion.
4. **Results files**: Write to `results/<category>/<descriptive_name>.json`
   or `.h5`. Never overwrite an existing results file — append a timestamp
   suffix instead: `core_fit_20260515.json`.
5. **ADS citations**: When adding a new reference, always call the ADS MCP
   `get_bibtex` tool and append the result to `paper/bibliography.bib`.
